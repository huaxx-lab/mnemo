# Provider icon notice

The OpenAI, Anthropic, Google, DeepSeek, Alibaba Cloud, MiniMax, OpenRouter and
LM Studio SVG paths in this directory are sourced from fixed releases of
[Simple Icons](https://github.com/simple-icons/simple-icons), whose repository
is CC0-1.0. Zhipu AI, SiliconFlow and Volcengine identification paths use the
public provider-logo assets exposed by the open-source
[models.dev](https://github.com/anomalyco/models.dev) catalog. Moonshot and
Ollama use compact local identification glyphs so the settings UI never needs
to download an icon at runtime. Brand names and marks remain the property of
their respective owners. They are used only to identify a provider and do not
imply endorsement.
