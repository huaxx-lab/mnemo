# Pinland UI 重构简报

## 目标屏幕

Mac 刘海入口、浅层投放反馈、收纳工作台与效率工作台。

## 必须出现的能力

- 明确点击打开，普通 hover 永不展开。
- 文件、图片、链接和文字拖近时才显示投放反馈，释放只添加一次。
- 收纳工作台展示剪贴板最近 5 条、Pin 卡片、搜索、预览与删除。
- 效率工作台包含待办、番茄钟和专注记录，按 P0 / P1 / P2 排序。
- 图片、PDF、链接和文本详情位于独立窗口。

## 视觉意图

安静、紧凑、原生 macOS 工具感。液体动效只用于入口和拖拽反馈，不用大面积黑色画布、装饰卡片或永久图标填充空间。

## 已给参考

- 用户提供的横向 Pin 轨道与下方独立编辑器截图，仅作为密度和层级灵感。
- NotchDrop、NotchKit 与 OpenNook 作为刘海几何、拖放和窗口生命周期参考。

## 硬约束

- 不同时动画 `NSWindow.frame` 与 SwiftUI 内容。
- 运行产物必须可识别版本且只允许单实例。
- 所有动态内容必须覆盖空态、长标题和大量数据。
